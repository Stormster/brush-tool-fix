[h1]Brush Tool Save Fix [B42][/h1]
Fixes the Build 42 multiplayer bug where Brush Tool tile placements and destroys only appear client-side and disappear after relog/restart.

Requires the mod on [b]BOTH[/b] the server and every client.

[h2]Server setup for Dedicated[/h2]
[list]
[*]Add this item's Workshop ID to [b]WorkshopItems=[/b]
[*]Add Mod ID [b]BrushToolSaveFix[/b] to [b]Mods=[/b]
[*]Restart the server (clients will auto-download on join/subscribe)
[/list]

Normal CO-OP/MP should work like every other mod.

[h2]What it fixes[/h2]
[list]
[*]Brush Tool place now runs on the server so tiles persist
[*]Brush Tool destroy is also server-authoritative
[/list]

[h2]Notes[/h2]
[list]
[*]Intended for B42.20+ dedicated / MP servers
[*]Enable Brush Tool via Admin Powers as usual
[*]Temporary workaround until a vanilla patch (could be a few years at this development rate..)
[/list]
