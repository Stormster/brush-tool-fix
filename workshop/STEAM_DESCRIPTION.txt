[h1]Brush Tool Save Fix [B42][/h1]
Makes admin Brush Tool edits in Build 42 multiplayer actually save, instead of vanishing after a relog, a chunk unload or a server restart.

PLEASE remember to leave a review so this mod gets in front of more users. Thanks guys!

[b]Still needed after 42.21? Yes.[/b] Vanilla now saves plain single tiles, but multi-tile objects still come out as one broken piece, overlays and attached decoration still cannot be removed, and failed edits still say nothing. Versions before 1.2.1 do [b]NOT[/b] work on 42.21.

[h2]What it does[/h2]
[list]
[*]Placed and destroyed tiles survive relogs, chunk unloads and server restarts
[*]Multi-tile objects (ovens, tents, boulders) are placed whole. Vanilla leaves a single piece that nothing can remove
[*]Overlays and attached decoration (stains, ground blending, screens) can be destroyed
[*]When an edit cannot be done you get a message instead of silence
[/list]

[h2]Setup[/h2]
[list]
[*]The mod must be on the server [b]AND[/b] every client
[*]Dedicated server: add the Workshop ID to [b]WorkshopItems=[/b] and [b]BrushToolSaveFix[/b] to [b]Mods=[/b], then restart
[*]Hosted / co-op: enable it in the server settings editor like any other mod
[*]Build 42.21 or newer
[/list]

[h2]Using it[/h2]
[list]
[*]You need [b]admin[/b]. The tool is under right-click > [b]Debug[/b] > [b]Brush Tool[/b]. The Brush Tool switch in Admin Powers does nothing
[*]Other roles: opening the Debug menu needs the UseDebugContextMenu capability, and edits need Brush Tool Manager. If you can see the menu but not use the brush, you get a message saying so
[*]Not working? Update the mod on the server and every client, then check the server console for a line starting with [BrushToolSaveFix. No line means the server did not load it
[/list]

[h2]Good to know[/h2]
[list]
[*]Overlays drawn by the object itself (a powered TV, a lit stove, container contents) come back when the game redraws them
[*]A multi-tile object that cannot be placed complete is refused on purpose, rather than leaving a piece you could never delete
[/list]
