title=Brush Tool Save Fix [B42]
description=Fixes the Build 42 multiplayer bug where Brush Tool tile placements and destroys only show up on your own screen and vanish after a relog or restart.
description=
description=Requires the mod on BOTH the server and every client.
description=
description=Server setup for Dedicated:
description=1) Add this item's Workshop ID to WorkshopItems=
description=2) Add Mod ID BrushToolSaveFix to Mods=
description=3) Restart the server (clients will auto-download on join/subscribe)
description=
description=Normal CO-OP/MP should work like every other mod.
description=
description=What it fixes:
description=- Tiles you place stay placed. They survive walking away, relogging and server restarts
description=- Destroying tiles works the same way
description=- Big objects that cover more than one tile (ovens, tents, boulders) now place as a complete object. Before you got a single piece that nothing could remove, not the Brush Tool, not the admin panel, not even a sledgehammer
description=- You can now destroy overlays and attached decoration such as stains, ground blending and screens. Vanilla let you copy those but never remove them
description=- When an edit cannot be done you get a message, instead of it quietly doing nothing
description=
description=Good to know:
description=- Some overlays are drawn by the object itself, like a powered TV screen, a lit stove, or whatever is sitting in a container. Removing those only lasts until the game draws them again. Nothing is broken, they just cannot be removed that way
description=- If a multi-tile object cannot be placed complete, the placement is refused on purpose. That is better than leaving a piece behind that you could never delete
description=
description=Notes:
description=- Intended for B42.20+ dedicated / MP servers
description=- Enable Brush Tool via Admin Powers as usual
description=- Temporary workaround until a vanilla patch (could be a few years at this development rate..)
description=- Want the technical details? https://github.com/Stormster/brush-tool-fix
