title=Brush Tool Save Fix [B42]
description=Makes admin Brush Tool edits in Build 42 multiplayer actually save, instead of vanishing after a relog, a chunk unload or a server restart.
description=
description=PLEASE remember to leave a review so this mod gets in front of more users. Thanks guys!
description=
description=Still needed after 42.21? Yes. Vanilla now saves plain single tiles, but multi-tile objects still come out as one broken piece, tiles placed in open air on upper floors are silently dropped, overlays and attached decoration still cannot be removed, and failed edits still say nothing. Versions before 1.2.1 do NOT work on 42.21.
description=
description=What it does:
description=- Placed and destroyed tiles survive relogs, chunk unloads and server restarts
description=- Multi-tile objects (ovens, tents, boulders) are placed whole. Vanilla leaves a single piece that nothing can remove
description=- Grime, blood, graffiti and other overlay tiles sit on the floor or wall like the mapped ones, instead of flickering against it
description=- Overlays and attached decoration (stains, ground blending, screens) can be destroyed
description=- When an edit cannot be done you get a message instead of silence
description=
description=Setup:
description=- The mod must be on the server AND every client
description=- Dedicated server: add 3775272983 to WorkshopItems= and BrushToolSaveFix to Mods=, then restart
description=- Hosted / co-op: enable it in the server settings editor like any other mod
description=- Build 42.21 or newer
description=
description=Using it:
description=- You need admin. The tool is under right-click > Debug > Brush Tool. The Brush Tool switch in Admin Powers does nothing
description=- Other roles: opening the Debug menu needs the UseDebugContextMenu capability, and edits need Brush Tool Manager. If you can see the menu but not use the brush, you get a message saying so
description=- Not working? Update the mod on the server and every client, then check the server console for a line starting with [BrushToolSaveFix. No line means the server did not load it, and the line shows which version it is running
description=
description=Good to know:
description=- Overlays painted with 1.2.2 or older flicker against the tile under them. Destroy them and paint them again to fix it
description=- Overlays drawn by the object itself (a powered TV, a lit stove, container contents) come back when the game redraws them
description=- A multi-tile object that cannot be placed complete is refused on purpose, rather than leaving a piece you could never delete
